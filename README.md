# **T3CO**: Transportation Technology Total Cost of Ownership Tool

## What is T3CO?

T3CO is a comprehensive, fast, and free open-source analysis tool that calculates the total cost of ownership (TCO) for commercial vehicles with various powertrain technologies (conventional, electric, hybrid, hydrogen fuel cell, etc.). Developed by the National Renewable Energy Laboratory (NREL), it helps fleet operators, researchers, and policymakers make data-driven decisions by comparing lifetime costs across different vehicle technologies.

## Key Features

- **Complete TCO Analysis**: Calculate purchase costs, operational expenses, fuel consumption, maintenance, infrastructure, and more. View comprehensive results generated by T3CO.
- **Opportunity Cost Analysis**: Evaluate the soft-cost impact of maintenance downtime, chargingg/fueling downtime, and lost payload capacity
- **Vehicle Simulation Integration**: Runs detailed vehicle simulations to accurately estimate energy consumption under real-world driving conditions. Integrated with NREL's FASTSim powertrain simulation tool.
- **Multiple Powertrain Support**: Analyze conventional, electric, hybrid, hydrogen fuel cell, and other advanced powertrains
- **Performance Evaluation**: Assess vehicle range, acceleration, and gradeability
- **Optimization Capabilities**: Optimize vehicle powertrain configurations to meet performance targets while minimizing costs
- **Highly Customizable**: Model different drive cycles, usage patterns, fuel prices, and infrastructure requirements
- **Fast Execution**: Efficient algorithms and multiprocessing support enable rapid analysis of multiple scenarios and vehicle configurations.
- **Visualization Tools**: Generate charts and plots to compare technologies and understand cost breakdowns
- **Free and Open Source**: Completely free to use with full source code available under open license

## Installation

T3CO requires Python 3.8, 3.9, or 3.10.

### Option 1: Using venv (Python)

```bash
# Create and activate a Python environment (recommended)
python -m venv t3co_env
source t3co_env/bin/activate  # On Windows: t3co_env\Scripts\activate

# Install T3CO
pip install t3co
```

### Option 2: Using conda

```bash
# Create and activate a conda environment (recommended)
conda create -n t3co python=3.10
conda activate t3co

# Install T3CO from PyPI using pip within the conda environment
pip install t3co
```

### Getting Demo Input Files

T3CO comes with demonstration input files to help you get started:

```bash
# After installing T3CO, run:
install_t3co_demo_inputs
# Answer 'y' when prompted
# Enter '.' to copy to current directory or specify another path
```

## Basic Usage

T3CO requires three main input file types to run an analysis:

1. **Vehicle** files define technical specifications of vehicles
2. **Scenario** files define operational and cost parameters
3. **Config** files specify which analyses to run and link to input files

### Running Your First Analysis

```bash
# Navigate to the directory with demo input files
cd demo_inputs  # If you saved them to a folder named demo_inputs

# Run a sample analysis
python -m t3co.sweep --analysis-id=0 --config=T3COConfig.csv
```

This command analyzes the vehicle-scenario pairs defined in the "selections" column of the first row (ID=0) of the Config file.

### Viewing Results

Results are saved as CSV files in the directory specified in your Config file (default: `./results`). The results include:

- Total cost of ownership($)
- Breakdown of costs by category (vehicle, fuel, maintenance, etc.)
- Performance metrics (range, acceleration, etc.)
- All input parameters used in the analysis

### Visualizing Results

T3CO includes visualization tools to help interpret results:

```bash
# Run the visualization demo (after generating results)
python -m t3co.demos.visualization_demo
```

## Input File Structure

### Vehicle File

A CSV file with columns for powertrain specifications:

- Engine power
- Battery capacity
- Vehicle component masses
- Aerodynamic parameters
- And many other vehicle attributes

### Scenario File

A CSV file with columns for operational parameters:

- Annual vehicle miles traveled (VMT)
- Vehicle lifetime
- Purchase price inputs
- Fuel and electricity prices
- Opportunity Cost inputs

### Config File

A CSV file that controls which analyses to run:

- Vehicle-scenario pairs to analyze
- File paths for inputs and outputs
- Optimization settings
- Global parameter overrides

## Advanced Features

### Multi-processing

For faster analysis of multiple scenarios, see [Running Multiple Analyses in Parallel](https://github.com/NREL/T3CO/blob/main/docs/quick_start.md#running-multiple-analyses-in-parallel) in the Quick Start Guide.

```bash
python -m t3co.sweep --analysis-id=0 --run-multi --n-processors=4
```

### Batch Mode for Multiple Drive Cycles

For analyzing multiple drive cycles efficiently, see [Running Batch Analyses with Multiple Drive Cycles](https://github.com/NREL/T3CO/blob/main/docs/quick_start.md#running-batch-analyses-with-multiple-drive-cycles) in the Quick Start Guide.

```bash
python -m t3co.sweep --analysis-id=3  # Uses a config with drivecycle folder path
```

### Customizing Analyses

To create and modify your own analyses, see [Customizing Your Analysis](https://github.com/NREL/T3CO/blob/main/docs/quick_start.md#customizing-your-analysis) in the Quick Start Guide.

```bash
python -m t3co.sweep --analysis-id=1
```
